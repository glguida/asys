# Slate

A contrasting dashboard design with bundled Yrsa serif fonts, rounded task
marks, circular gateways, a new logo and dark cards. Agent, goal, Senate, swarm,
program and human work keep separate colors. World backgrounds, labels and
marks use the same palette as the rest of the dashboard.

From a checkout, open it beside another dashboard:

```sh
asys dashboard --root ./state --port 8776 --design ./designs/slate
```

An installation also includes this package at `PREFIX/share/asys/designs/slate`.
Copy it to start your own design. See the
[design authoring guide](../../skills/asys-authoring/references/design.md).
